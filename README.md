## Описание проекта

Система машинного обучения для прогнозирования вероятности совершения целевого действия (конверсии) на сайте сервиса долгосрочной аренды автомобилей "СберАвтоподписка".

Модель анализирует поведенческие паттерны пользователей и характеристики визита для оценки вероятности оформления заявки, заказа звонка или другого целевого действия.


**О компании «СберАвтоподписка»**
СберАвтоподписка — это сервис долгосрочной аренды автомобилей для физических лиц. Клиент платит фиксированную сумму в месяц и получает авто в пользование сроком от 6 месяцев до 3 лет.

В стоимость включены:
- Страхование (КАСКО, ОСАГО, ДСАГО);
- ТО и ремонт;
- Сезонная смена и хранение шин;
- Круглосуточная поддержка.

Дополнительно можно заказать консьерж-сервис — доставка автомобиля в сервис и обратно.

Сервис выступает альтернативой покупке авто или автокредиту — машину выгоднее арендовать, а средства инвестировать.

Решение представленное в данной работе поможет:

- Оценивать эффективность каналов привлечения трафика;
- Адаптировать рекламные кампании;
- Улучшать UX сайта за счет анализа поведения пользователей.

### API эндпоинты

**GET / - Главная страница**

Веб-интерфейс для ввода параметров и получения предсказаний.

**POST /predict - Получение предсказания**

Запрос:

```json
{
    "visit_number": 2,
    "visit_hour": 14,
    "visit_dayofweek": 3,
    "visit_month": 6,
    "total_hits": 25,
    "unique_pages": 8,
    "car_page_views": 3,
    "form_interactions": 2,
    "session_duration_sec": 180,
    "screen_width": 1920,
    "screen_height": 1080,
    "device_category": "desktop",
    "is_organic": false,
    "is_social": false
}
```
Ответ:

```json
{
    "status": "success",
    "probability": 0.7845,
    "predicted_class": 1,
    "conversion_level": "high",
    "level_description": "Высокая вероятность конверсии"
}
```
**GET /health - Проверка состояния сервиса**
```json
{
    "status": "healthy",
    "model_loaded": true,
    "service": "conversion_predictor",
    "version": "1.0.0"
}
```
**GET /features - Список признаков модели**
```json
{
    "status": "success",
    "feature_count": 30,
    "features": ["visit_number", "visit_hour", ...]
}
```

| Уровень вероятности | Цвет | Значение | Рекомендация |
|---------------------|------|----------|---------------|
| Высокий (>70%) | Зеленый | Высокая вероятность конверсии | Показать специальное предложение, активировать быструю обработку |
| Средний (30-70%) | Желтый | Неопределенная ситуация | Предложить помощь оператора, показать преимущества подписки |
| Низкий (<30%) | Красный | Низкая вероятность конверсии | Улучшить вовлечение, предложить бонус или демо-версию |
